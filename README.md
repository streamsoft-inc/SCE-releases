# SCE — Releases

Builds of **SCE** (Spectral Coherence Control — Essentials), a Planet Venus Audio plug-in from Sonic Studio
for macOS (AU, VST3 and AAX). This repository distributes the plug-in; it is
not where SCE is developed and contains no source code.

## Downloading

Open [Releases](../../releases) and download the `SCE.<version>.zip`
asset from the newest entry. That zip contains the signed, notarized installer.

The plug-in requires an **SCE** iLok licence.

Release notes for every version: [RELEASE-NOTES.md](RELEASE-NOTES.md), or as a
web page at https://streamsoft-inc.github.io/SCE-releases/

## About the "Source code" downloads

Every release also lists **Source code (zip)** and **Source code (tar.gz)**.
Those are generated automatically by GitHub for the release's tag and cannot be
turned off. They contain only this README and the release notes.

**They are not SCE's source, and they are not the plug-in.** If you are
looking for the build, use the `SCE.<version>.zip` asset above.
